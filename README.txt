## Add the same song
Put your audio file in this folder and name it exactly:
music.mp3

Then open index.html and tap the ♪ button.

## Add photos later
A photo gallery/couple-photo section can be added once you provide the photos.

## Publish free on GitHub Pages
1. Create a new GitHub repository.
2. Upload index.html, style.css, script.js and music.mp3.
3. In Settings → Pages, select the main branch and root folder.
4. GitHub will provide your public invitation URL.
